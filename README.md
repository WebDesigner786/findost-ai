# FinDost AI

**Financial Operations Assistant for Pakistani Students, Households, SMEs, and Enterprises**  
Built for the **AICON'26 Build With AI** Competition.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run developer server
npm run dev

# 3. Open in browser
# http://localhost:3000
```
